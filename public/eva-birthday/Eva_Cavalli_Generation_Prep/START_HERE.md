# Eva — generation preparation, version 1

An 18-shot, 60-second proposed edit based on the original memory-dream concept. Eva remains the centre; the recurring table grows from home into a world of family and friends. This pack contains briefs and source references, not generated starting frames or completed videos.

Working defaults: 16:9, 1920×1080 edit, 24 fps timeline, warm natural light, subtle grain added consistently during finishing, gentle motion, no dialogue or lip-sync. Durations are edit targets, not claims about a model’s supported clip lengths. Music and personal sound recordings are still to be chosen. The ending uses age 67 for the planned October 2026 birthday.

## Start with three tests

1. S02: Eva as a teenager — first prepare an Eva-only identity crop from 032; do not include the tailor. Check likeness against both 032 and the fourth woman in 030. Approve the still before motion.
2. S11: Eva and Roberto — use original 002 as the starting frame. Test subtle motion and whether two identities remain stable.
3. S07: the table motif — design a face-free table still, then test plate placement. This tests the central visual motif while family references are pending.

Generate a few still variants per test, choose one, then test one restrained video. Change one variable at a time. If likeness fails, return to the starting frame and reference assignment. Avoid spending credits on the full sequence before these pass.

## Production workflow

For each shot, open its SHOT_BRIEF.md and reference files. Prepare identity crops separately from context references; keep the original files intact. Do not use a group photo as an undifferentiated identity input. Label each uploaded reference by person, era and role (identity, setting, wardrobe or composition), using the reference syntax supported by the chosen Higgsfield model.

First approve era-specific identity stills. Save approved characters, settings and props as reusable references/Elements where available. Then make one starting frame per shot using the brief. Inspect identity, age, hands, faces, costume and background. Only approved stills proceed to video. Model choice, available reference controls and clip duration must be checked in the account’s current interface; this pack does not assume every model supports the same controls.

Use photo animation sparingly; editorial pans over the unchanged archive images are often the better option. Use cuts, flashes and foreground wipes in the edit to cross decades. Create the expanding table through separate layouts and inserts, preserving the same linen, plates, candles and light direction. Avoid complex ageing transformations and a single generation containing the entire extended family.

Store approved stills in approved_stills/ and video exports in generated_clips/. Name them S02_still_v01 and S02_video_v01, etc. Record the exact model, settings, reference files, prompt and chosen version in generation_log.json. No model, seed or generation outcome is recorded as though a test has already run.

## What still needs the family archive

- Childhood: identified Eva photo, approximate date, parents identified and actual home/location.
- 1980s–1990s: Eva with each child at the relevant age, young-family group, Sardinia table and home photos.
- Present day: recent Eva portrait or short video, and the place where she feels happiest now.
- Next generation: names, relationships, chosen shared photographs and who belongs in the film.
- Relationships: a private Eva–Roberto moment, Eva with Marta, Cindy with Eva, and shared family imagery if Tommaso/Cristiana should feature.

Adult portraits cannot supply authentic baby likenesses. Undated portraits do not establish present-day appearance. Reference rights and credits travel with each pack; reference downloads have not acquired film-use licences.

## Review gate before each video

Does this look like the intended person at this age? Are all people correctly assigned? Are hands and faces sound? Does the location and costume fit the scene? Is the action simple and emotionally useful? Is a reconstructed scene clearly distinguished from genuine archival material? If any answer fails, fix the still first.
