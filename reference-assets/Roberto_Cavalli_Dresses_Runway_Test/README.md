# Roberto Cavalli — five dress references for runway transformation test

An iconic editorial selection, not a measured popularity ranking. All five are Cavalli looks from the founder’s creative era; the 2015–2016 Peter Dundas looks are not mixed into this set. Original public image files retained without editing or upscaling. Source URLs, credits and dimensions are in manifest.csv.

1. Aaliyah: yellow/black zebra silk, Fall 2000. Comparison photo includes Paloma Elsesser wearing the same design at left and Aaliyah at right.
2. Cindy Crawford: snakeskin-print gown, 2003.
3. Victoria Beckham: turquoise/lime cutout gown, Fashion Rocks 2005.
4. Karolina Kurkova: gold embellished gown and jacket, Spring/Summer 2012.
5. Sharon Stone: cobalt-blue plunging gown, Cannes 2013.

For the test, treat these as GARMENT references only. Keep Eva’s identity reference separate, and do not inherit the celebrity wearer’s face or body. Approve five full-body Eva stills on the same runway with the same framing, pose, lighting and hair before animation. Preserve each outfit’s silhouette and materials. Test one transition first, then assemble the five-look sequence. Keep shoes and walk direction consistent; distinguish dress changes from jacket/jewellery changes.
